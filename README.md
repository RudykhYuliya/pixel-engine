# pixel-engine

Один файл, без библиотек. Холст на целых пикселях и один цикл кадра: им можно крутить и ролик, и игру.

Открой `index.html`. Человек сам ходит по улице. Стрелки забирают шаг, пробел ставит паузу.

## Подключение

```html
<canvas id="screen"></canvas>
<script src="pixel-engine.js"></script>
<script>
  const px = Pixel.mount(document.getElementById("screen"), 320, 180);
  const sky = [
    [8, 12, 28],
    [22, 34, 62],
    [34, 48, 78],
  ];

  px.start(function () {
    px.cls([6, 8, 16]);
    px.bands(0, 0, 320, 100, sky);
    px.orb(40, 30, 10, Pixel.ramp("#f0d7a4", { steps: 5 }), {
      outline: "broken",
      light: { x: -1, y: -0.4 },
    });
  });
</script>
```

Цвет везде `[r, g, b]` от 0 до 255. Координаты целые. Камера тоже в целых пикселях: `px.cam(x, y)`.

## На чем держится картинка

Приемы не из одного стиля. Их повторяют разные авторы, и функции ниже делают именно это.

Рампа, `Pixel.ramp(цвет, { steps, shadowHue, lightHue })`. Средняя ступень - сам цвет. Тень темнее и с холодной подмесью (по умолчанию оттенок 232), свет теплее (42). Оттенок не крутится по кругу: у желтого на пути к синему получается красный клин, и шар читается как диаграмма. У лампы тень лучше взять оранжевой (`shadowHue: 28`), потому что ее окружение - она сама.

Плоская грань - один `rect` одним цветом. Круглое рисует `orb`: свет с одной стороны, граница света резкая, блик из двух пикселей, в нижней части тени узкая полоска отскока от земли. Темного ободка вокруг всего шара нет.

Контур у `blit` и `orb`. Режимы:

- `none` - без контура
- `black` - почти черный
- `dark` - темнее чернил
- `area` - темнее соседней заливки
- `lit` - светлая сторона контура светлее, теневая темнее
- `broken` - со стороны света контур прерывается

`light: { x, y }` - направление на источник, не обязательно единичное.

`shadow(x, y, rx)` - плоское пятно на земле. Это падающая тень, не обводка объекта.

`dither(x, y, w, h, a, b, amount)` - Bayer 4x4 между двумя соседними ступенями. На лицо и на спрайт, который едет каждый кадр, его лучше не класть: шахматка начинает мерцать.

`bands(x, y, w, h, colors, { seam: true })` кладет цвета твердыми полосами. `seam` добавляет один ряд дизера между ними. На все небо его лучше не включать: пунктир на 320 пикселей выглядит как строка развертки. Шов уместен на коротком переходе, где две ступени и так соседние.

`mark()`, потом объект, потом `reflect(rect, opt)`. В воду попадает только слой после `mark`, без неба и земли. Отражение короче (`shorten` по умолчанию 0.75), темнее и смешано с `water`. Четные ряды сдвинуты на пиксель, это едет от `time`. Нижняя треть редеет через пиксель. `ground` - линия, через которую зеркалим. `clip(x, y)` оставляет отражение внутри лужи.

Спрайт задается строками. Точка - пусто.

```javascript
const hero = Pixel.sprite(
  ["..kk..", ".kssk.", "..hh.."],
  { k: [244, 238, 228], s: [240, 194, 164], h: [247, 242, 232] }
);
px.blit(hero, 40, 20, { outline: "lit", light: { x: -1, y: -1 }, ink: [36, 22, 44] });
```

Клавиши лежат в `px.keys` по `event.code` (`ArrowLeft`, `Space`). `px.time` и `px.dt` обновляет `start`.

## Откуда приемы

- [How to Make Pixel Art](https://makebead.com/how-to-make-pixel-art/) - силуэт, плоский цвет, сдвиг оттенка, виды контура, кластер вместо одинокого пикселя. Одинокий пиксель уместен как глаз или блик.
- [Pedro Medeiros, Basic Shading](https://saint11.art/pixel_art_articles/article4/) и [Anti-alias](https://saint11.art/pixel_art_articles/article5/) - резкий терминатор, падающая тень, блик, свет отскока, антиалиас только на ступеньке длиннее одного пикселя.
- [Pixeli, вода](https://pixeli.pebbly.space/knowledge/rules/64-water) и [дизер](https://pixeli.pebbly.space/knowledge/rules/13-dithering-and-texture) - отражение короче и темнее, сдвиг полос, дизер только на шве.
